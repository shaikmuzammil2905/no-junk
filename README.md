## 📱 Features & Highlights

- **Original Squirrel Badge Identity**: Preserves the original Kraft-paper badge, squirrel illustration, chocolate brown palette, and authentic typography.
- **Animated Splash Screen**: Elegant 1.8s intro animation with logo, squirrel mascot, and brand tagline before transitioning into the homepage.
- **Mobile-First Experience**: Faithful recreation of the reference design with pill category filters, mobile search bar, sticky bottom navigation (Home, Shop, Wishlist, Contact), and slide-in drawer.
- **Shop & Category Filtering**: Browse Loose Nuts, Gift Packs, and Chocolate Specials with instant variant chip selectors (pack sizes, pcs count, pricing).
- **Signature Treat Spotlight**: Dedicated showcase for the crown jewel — *Stuffed and Studded Chocolate Medjool Dates*.
- **Individual Product Detail Pages**: High-resolution gallery zoom, pack selector, live price calculation, highlights, storage care guidelines, and interactive related products.
- **Dynamic WhatsApp Ordering**: Product-wise dynamically prefilled enquiry messages with selected pack sizes and pricing.
- **Floating WhatsApp Widget**: Fixed pulse-animated floating button with an interactive greeting popup for instant chat.
- **Interactive Wishlist & Enquiry Basket**: Save favourite treats and aggregate multiple items into a single consolidated WhatsApp enquiry.
- **Curated Gifting & FAQ**: Dedicated gifting section for Festivals, Weddings, Birthdays, Corporate Hampers, and Return Gift Pouches + 10 interactive accordions with confirmed business information.

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v18+) and npm installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/shaikmuzammil2905/no-junk.git
cd no-junk

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
